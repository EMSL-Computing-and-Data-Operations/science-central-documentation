# Science Central™ Platform Overview

## Introduction

Science Central™ is EMSL's integrated research platform that provides a unified environment for scientific research, data analysis, collaboration, and computational modeling. The platform serves as a convergence point for innovation, collaboration, and scientific discovery.

## Platform Architecture

Science Central operates as a microservices-based platform with integrated authentication through Keycloak, providing seamless access to specialized research tools and environments.

### Core Components

The platform consists of three main components:

1. **Circles** - Collaboration and research sharing platform
2. **Modeling Workbench** - Machine learning and simulation environment
3. **Insight Engine** - Data analysis and visualization platform

## Authentication & Access

- **Single Sign-On**: Integrated Keycloak authentication across all components
- **User Workspaces**: Individual, secure environments for each researcher
- **Cross-Platform Integration**: Seamless navigation between all tools
- **Web-Based Access**: All functionality available through modern web browsers

## Technical Infrastructure

### Underlying Technologies
- **JupyterHub**: Powers notebook environments across multiple components
- **Open OnDemand**: High-performance computing access portal
- **Containerized Environments**: Optimized, isolated containers for each service
- **Modern Web Interface**: Responsive design for desktop and mobile access

### Integration Features
- Shared authentication and user management
- Cross-platform data sharing capabilities
- Unified user experience design
- Common file storage and management

## Getting Started

### Initial Access
1. Navigate to https://sc.emsl.pnnl.gov/
2. Authenticate using your EMSL credentials
3. Select the appropriate module for your research needs
4. Access your personal workspace and begin analysis

### Platform Navigation
- **All Modules**: Central dashboard showing all available components
- **Navigation Menu**: Quick access to frequently used tools
- **Help Documentation**: Comprehensive guides and tutorials
- **Support**: Direct access to EMSL support team

## Use Cases

Science Central serves researchers across multiple domains:

- **Computational Biology**: Multi-omics data analysis and integration
- **Machine Learning**: Model development and deployment
- **Data Science**: Statistical analysis and visualization
- **Collaborative Research**: Team-based project management
